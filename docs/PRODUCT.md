# 宋桌面 SongDesk 产品文档

> 为比亚迪宋PLUS DM-i（2021 款 · DiLink 3.0）打造的开源车机桌面
> 版本 1.0 · 2026-11-14 · 深空玻璃风

---

## 1. 产品定位

**一句话**：让老款比亚迪车机的桌面，长得像 2026 年该有的样子——好看、好按、好开。

**目标用户**：比亚迪宋PLUS DM-i 2021 款车主（DiLink 3.0，12.8″ 1920×1080 旋转屏）。核心痛点：原车桌面陈旧、第三方桌面（迪粉桌面）功能强但闭源且 UI 老旧。

**产品原则**（从逆向迪粉桌面 + 自身驾驶观察总结）：

| 原则 | 含义 | 落地 |
| --- | --- | --- |
| 行驶安全优先 | 高频操作 1 步可达，目标 ≥76dp | 主页快速温控条、快捷任务卡 |
| 信息要诚实 | 显示的数据必须标注来源 | 车况卡「●实车/●系统/●模拟」徽标 |
| 驾驶员时间粒度 = 秒 | 每一次交互少一跳 | 温度 3 步→1 步 |
| 夜间不刺眼 | 深色为主、无纯白 | 深空玻璃风 #0B0F1A |

## 2. 核心场景 → 功能映射

| 场景 | 用户动作 | SongDesk 支持 |
| --- | --- | --- |
| 上车出发前 | 看天气（带伞吗）看续航（要充电吗） | 状态条实时天气 + 预警；车况卡 SOC/续航/充电 |
| **行驶中（最高频）** | **调空调温度 ±1°** | **主页快速温控条：1 步、盲操可达** |
| 行驶中 | 切歌、改目的地 | Dock 音乐/地图降级链启动；回家/上班一键导航 |
| 冬天上车 | 除霜、加热座椅、升温 | 一键除霜 / 冬季模式 / 温控条 / 车控面板 |
| 下雨 | 关窗、除霜 | 一键关窗 / 雨天模式 |
| 泊车离车 | 关窗关空调确认 | 离车模式一键全关 |
| 装应用后 | 找到并打开新应用 | 应用网格自动枚举分页 |

**调温交互设计决策**：原路径 = 主页→车控→找温度→点±（3 跳 4 秒，行驶中危险）。现路径 = 主页车况卡底部温控条（1 跳 1 秒）。温控条固定位置（右卡底部），支持行驶中盲操；AC 徽标亮灭指示空调状态。

## 3. 功能架构（v1→v3 已实现）

```
主页
├─ 状态条：时钟/日期 + 实时天气(Open-Meteo) + 气象预警 + 蓝牙/信号
├─ 时钟·天气大卡（大字号时钟 + 天气 emoji/实温/今日范围/城市/预警）
├─ 车况卡：SOC/续航/充电⚡ + 来源徽标(实车/系统/模拟) + 门窗锁/档位 + 车内外温度
│         └─ 快速温控条 AC − 23° ＋（1 步调温）
├─ 快捷任务卡×5：回家 / 上班 / 一键除霜 / 一键关窗 / 开空调
├─ 应用网格：分页 6×3，自动枚举已装应用，长按菜单（打开/应用信息/卸载）
└─ Dock：地图 / 音乐 / 电话（多包名降级启动链）+ 车控 + 设置

车控页
├─ 智能场景：雨天模式 / 夏日模式 / 冬季模式 / 离车模式
├─ 空调：温度 18~28° / 风量 0~7 / 吹脸吹脚 / 前后除霜
├─ 车窗天窗：四门独立 + 天窗 + 一键关窗
├─ 座椅加热：主驾/副驾 0~3 档
└─ 指令面板：19 条小迪风格指令，分类列表，点击执行 + 结果回显

设置页
├─ 壁纸：4 张程序生成壁纸（深空星云/极光山脉/落日余晖/深海浪潮）
├─ 强调色：冰蓝 / 青绿 / 橙（切壁纸自动配对）
├─ 车机协议嗅探：记录原车广播原始字段，供真车校准
└─ 关于 / 退出桌面
```

## 4. 技术架构

- **Kotlin + Jetpack Compose**（Material3 darkColorScheme 定制），minSdk 28 / target 35
- **CarBridge 抽象**：UI 只依赖接口；`DiLink3Bridge`（真车：AUTOVOICE 广播 + 包名探测）与 `MockCarBridge` 可互换，未上车自动回落
- **CarRepository 多级遥测**：字段级优先级合并（REAL 广播 20 > SYSTEM 安卓系统 10 > MOCK 0）——真车数据一旦出现即锁定字段，Mock 不再覆盖；UI 徽标实时标注来源
- **协议嗅探**：上车开启后记录原车广播原始字段（logcat `SongDeskSniff`），用于校准迪粉逆向所得协议假设
- **天气双源**：MSN（国内可达，key 复用自迪粉桌面逆向）优先，Open-Meteo 兜底

## 5. 与迪粉桌面 v2.6 对比

| 维度 | 迪粉桌面 | SongDesk |
| --- | --- | --- |
| 代码 | 闭源 + 百度加固 + 混淆（813 类） | 全开源 Compose（13 文件） |
| UI 风格 | 功能堆叠，审美老化 | 深空玻璃风，信息分层 |
| 车况数据 | ✅ 原车接口（成熟） | ⚠️ 架构就绪，真车待校准 |
| 指令系统 | 298 条 | 19 条核心（引擎已就绪，扩表即可） |
| 语音 AI | ✅ LLM 助理 | 未做（提示词与架构已逆向摸清） |
| 红绿灯读秒 | ✅ | 未做 |
| 影像联动 | ✅ | 未做 |
| 车友聊天/LED/第二屏 | ✅ | 不做（非核心） |

**结论**：SongDesk 用 1/60 的代码量覆盖了迪粉 60% 的高频功能，UI 全面现代化；长板是可维护性与设计，短板是真车协议成熟度。

## 7. 上车校准指南

1. U 盘拷 `app-debug.apk` → 车机安装 → 设为默认桌面
2. 设置 → 开启「车机协议嗅探」
3. `adb logcat -s SongDeskSniff`（车机开无线 ADB 或 USB）抓原车广播字段
4. 把抓到的字段回传 → 修改 `BroadcastTelemetryProvider` 解析映射 → 车况即真实

## 8. 已知限制

- 空调/车窗指令的实际下发协议为推断（AUTOVOICE 广播），需真车验证
- 快捷任务「回家/上班」依赖地图应用的关键字解析（高德车机版两步广播在部分固件需先搜后选）
- Mock 遥测仅为演示；模拟器无动力电池概念
